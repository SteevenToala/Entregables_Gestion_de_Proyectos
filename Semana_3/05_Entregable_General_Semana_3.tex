\section{Introducción}
La Semana 3 marcó el inicio formal de la **Fase 3: Desarrollo Iterativo Core** del proyecto SIGE, ejecutando el **Sprint 1 (Infraestructura, Persistencia y Base Frontend)**. Durante este ciclo de trabajo de 6 días laborables netos (07 al 14 de septiembre de 2026), el equipo cumplió con el 100\% de los objetivos planteados en el cronograma EDT: migraciones EF Core en PostgreSQL 16 (\texttt{EDT 3.1}), seeders institucionales SGC (\texttt{EDT 3.2}), autenticación JWT y roles RBAC (\texttt{EDT 3.3}), y cliente base en React 19 + Vite (\texttt{EDT 3.4}).

\section{Objetivo}

\subsection{Objetivo General}
Consolidar y validar los resultados técnicos, métricas de esfuerzo y software operativo generados durante el Sprint 1 de la Fase 3, certificando la estabilidad de la base sobre la cual se implementará el Sprint 2.

\subsection{Objetivos Específicos}
\begin{itemize}[leftmargin=1.5em, itemsep=1.5pt, topsep=1.5pt]
    \item Presentar el balance de horas ejecutadas vs. planificadas en el cronograma MS Project.
    \item Validar la integración transversal entre React 19 y la WebAPI .NET 9 mediante JWT.
    \item Formalizar la aprobación del incremento del Sprint 1.
\end{itemize}

\section{Alcance}

\subsection{Límites del Incremento (In-Scope)}
\begin{itemize}[leftmargin=1.5em, itemsep=1.5pt]
    \item Abarca los 4 paquetes EDT del Sprint 1 (EDT 3.1 al EDT 3.4).
    \item Balance de 128 horas de ingeniería ejecutadas por el equipo de 4 integrantes.
    \item Integración transversal de persistencia en PostgreSQL 16, autenticación JWT y cliente base en React 19.
\end{itemize}

\subsection{Exclusiones (Out-of-Scope)}
\begin{itemize}[leftmargin=1.5em, itemsep=1.5pt]
    \item No incluye los componentes de Wizard modular ni integración de firmas digitales (Semana 4).
\end{itemize}

\section{Definiciones}
\begin{itemize}[leftmargin=1.5em, itemsep=2pt, topsep=2pt]
    \item \textbf{Sprint Review:} Ceremonia ágil de inspección donde el equipo demuestra el incremento terminado.
    \item \textbf{DoD (Definition of Done):} Criterios de aceptación técnica para dar por completada una historia de usuario.
    \item \textbf{EDT (\textit{Estructura de Desglose del Trabajo}):} Jerarquía desglosada de entregables del proyecto.
\end{itemize}

\subsection{Demostración del Incremento de Software}
\begin{enumerate}[leftmargin=1.5em, itemsep=2pt]
    \item \textbf{Base de Datos Operativa:} Contenedor Docker \texttt{sige-postgres} con 13 tablas, llaves UUID e índices compuestos.
    \item \textbf{WebAPI Funcional:} Contenedor \texttt{sige-webapi} en .NET 9 exponiendo Swagger con endpoints seguros de autenticación.
    \item \textbf{Frontend React 19:} Aplicación web interactiva que permite inicio de sesión por roles y navegación a dashboard institucional.
\end{enumerate}

\subsection{Conclusiones y Recomendaciones Técnicas}
\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
    \item El Sprint 1 concluyó de manera exitosa con el 100\% de entregables finalizados según el cronograma de Ambato.
    \item La arquitectura de contenedores locales en Docker garantiza un entorno reproducible y estable para el inicio del Sprint 2.
    \item Avanzar de forma prioritaria en el Sprint 2 con el editor TipTap y la integración criptográfica del API de firmas electrónicas (FirmaEC).
\end{itemize}
