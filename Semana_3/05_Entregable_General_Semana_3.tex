% 2. INTRODUCCIÓN
% =============================================================
\section{Introducción}
La Semana 3 marcó el inicio formal de la \textbf{Fase 3: Desarrollo Iterativo Core} del proyecto SIGE, ejecutando el \textbf{Sprint 1 (Infraestructura, Persistencia, API REST y Base Frontend)} bajo la arquitectura monorepo canónica \texttt{SIGE/}. Durante este ciclo de desarrollo de 6 días laborables netos (07 al 14 de septiembre de 2026), el equipo cumplió con el 100\% de los objetivos planteados en la EDT:
\begin{enumerate}[leftmargin=1.5em, itemsep=1.5pt]
    \item Creación del esquema relacional ACID en PostgreSQL 18 mediante scripts DDL canónicos (\texttt{schema.sql} y script de inicialización \texttt{init.js}) con pool \texttt{pg.Pool} (\texttt{EDT 3.1}).
    \item Implementación de seeders institucionales \texttt{seed.sql} con usuarios semilla, roles FISEI y contraseñas hasheadas mediante Bcrypt.js (\texttt{EDT 3.2}).
    \item Arquitectura de seguridad integral en Node.js + Express (v5) con Bcrypt.js (12 salt rounds), tokens JWT (Access de 15m y Refresh de 7d), blindaje defensivo con Helmet y control RBAC por middlewares (\texttt{EDT 3.3}).
    \item Inicialización del cliente web SPA en React + Vite con Tailwind CSS, animaciones por GPU (CSS Keyframes), paleta institucional \texttt{\#00345E} y cliente Axios con auto-renovación silenciosa (\texttt{EDT 3.4}).
\end{enumerate}

Este informe consolida los resultados técnicos, métricas de esfuerzo y el incremento de software potencialmente desplegable del Sprint 1.

\section{Objetivo}

\subsection{Objetivo General}
Consolidar y validar los resultados técnicos, procedimentales y artefactos de software generados durante el Sprint 1 de la Fase 3, certificando la operatividad de la infraestructura base (Node.js Express v5, PostgreSQL 18, React + Vite) para el inicio inmediato del Sprint 2 (Semana 4).

\subsection{Objetivos Específicos}
\begin{itemize}[leftmargin=1.5em, itemsep=1.5pt, topsep=1.5pt]
    \item Presentar el balance de horas ejecutadas vs. horas planificadas en el cronograma de Ambato.
    \item Validar la integración transversal end-to-end entre el cliente React + Vite y el backend Express v5 mediante autenticación segura JWT y persistencia en PostgreSQL 18.
    \item Registrar formalmente la revisión y cierre del Sprint 1 habilitando el paso a la Semana 4.
\end{itemize}

\section{Definiciones}
\begin{itemize}[leftmargin=1.5em, itemsep=2pt, topsep=2pt]
    \item \textbf{Sprint Review:} Ceremonia ágil de inspección donde el equipo demuestra el incremento funcional de software al tutor y revisores.
    \item \textbf{Incremento de Software:} Versión operativa, probada e integrada del producto al cierre de un ciclo de desarrollo.
    \item \textbf{Monorepo:} Estrategia arquitectónica donde el código backend y frontend reside en un único repositorio estructurado (\texttt{SIGE/}).
    \item \textbf{EDT (\textit{Estructura de Desglose del Trabajo}):} Jerarquía desglosada de entregables del proyecto.
\end{itemize}

\subsection{Demostración del Incremento de Software}
\begin{enumerate}[leftmargin=1.5em, itemsep=2pt]
    \item \textbf{Base de Datos Operativa:} Instancia de PostgreSQL 18 corriendo en puerto 5432 con 13 tablas normalizadas en 3FN, llaves primarias UUID, índices compuestos y datos iniciales inyectados mediante \texttt{seed.sql}.
    \item \textbf{Backend API REST Funcional:} Servidor Node.js + Express (v5) en puerto 5000 con arquitectura modular, blindaje de cabeceras HTTP Helmet, hashing Bcrypt.js (12 salt rounds) y endpoints \texttt{/api/auth/login}, \texttt{/api/auth/refresh}, \texttt{/api/auth/me}.
    \item \textbf{Frontend React + Vite:} Interfaz SPA en puerto 5173 con diseño institucional \texttt{\#00345E}, gestión global con \texttt{AuthContext.jsx}, rutas protegidas y cliente Axios con auto-renovación silenciosa de tokens.
\end{enumerate}

\subsection{Conclusiones y Recomendaciones Técnicas}
\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
    \item El Sprint 1 culminó con éxito en el plazo planificado (14 de septiembre de 2026), cumpliendo las 128 horas de esfuerzo conjunto programadas en la EDT.
    \item El stack unificado en JavaScript moderno (Node.js en backend y React en frontend) aceleró el ciclo de desarrollo y simplificó los contratos de comunicación API REST.
    \item Avanzar de forma prioritaria en el Sprint 2 (Semana 4) con los controladores de documentos, flujos de dictamen y exportación institucional de informes.
\end{itemize}
