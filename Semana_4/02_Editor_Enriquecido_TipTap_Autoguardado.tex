\section{Título}
\textbf{Denominación del Entregable:} Integración del Editor Enriquecido TipTap con Autoguardado Asíncrono Debounce (1.5s) en React + Vite hacia API REST Express v5



% =============================================================
% 2. INTRODUCCIÓN
% =============================================================
\section{Introducción}
En la elaboración de planes de trabajo e informes de cumplimiento, las secciones descriptivas (Antecedentes, Justificación, Metodología de Cátedra, Conclusiones y Recomendaciones) demandan una redacción fluida con soporte para negritas, listas ordenadas, viñetas y formato estructurado conforme a la norma ISO 9001:2015 del SGC. El empleo de cajas de texto planas (\texttt{textarea}) degrada la experiencia de usuario y no genera la semántica enriquecida requerida para la posterior exportación documental.

Para subsanar esta limitación, se integró el motor de edición enriquecida \textbf{TipTap} (construido sobre el estándar \textit{ProseMirror}) en el cliente \textbf{React + Vite}. Para blindar al docente contra cualquier pérdida involuntaria de información por cortes de fluido eléctrico o intermitencias de red en el campus, se implementó un mecanismo de \textbf{autoguardado asíncrono en segundo plano mediante un Hook personalizado \texttt{useAutoSaveSection} con Debounce calibrado a 1500 ms}, informando en tiempo real el estado de sincronización hacia el backend Node.js + Express (v5) y la base de datos PostgreSQL (18).

% =============================================================
% 3. OBJETIVO
% =============================================================
\section{Objetivo}

\subsection{Objetivo General}
Implementar el componente de edición enriquecida \texttt{RichTextEditor.jsx} en React y Vite basado en TipTap, dotándolo de herramientas de formato tipográfico institucional, sanitización XSS y sincronización asíncrona automatizada hacia la API REST de Express v5.

\subsection{Objetivos Específicos}
\begin{itemize}[leftmargin=1.5em, itemsep=1.5pt, topsep=1.5pt]
    \item Configurar TipTap con extensiones esenciales: \texttt{StarterKit}, \texttt{Bold}, \texttt{Italic}, \texttt{BulletList}, \texttt{OrderedList}, \texttt{Heading} e \texttt{History (Undo/Redo)}.
    \item Diseñar el Hook reactivo \texttt{useAutoSaveSection} para emitir solicitudes HTTP \texttt{PUT /api/documentos/:id/secciones} únicamente tras 1.5 segundos de inactividad del teclado, evitando sobrecarga innecesaria en el servidor.
    \item Implementar badges visuales reactivos en la interfaz: \texttt{[Guardando...]}, \texttt{[Guardado en PostgreSQL]} o \texttt{[Error de red - Reintentando]}.
    \item Sanitizar el contenido HTML generado mediante \texttt{DOMPurify} para neutralizar riesgos de inyección de código malicioso (XSS).
\end{itemize}

% =============================================================
% 4. ALCANCE
% =============================================================
\section{Alcance}

\subsection{Alcance Incluido}
Componente \texttt{RichTextEditor.jsx} modular y reutilizable para cualquier sección del expediente, Hook de autoguardado asíncrono con control de cancelación (\texttt{AbortController}), sanitización con DOMPurify y persistencia asíncrona sin bloquear la escritura en el cliente.

\subsection{Límites y Exclusiones}
No incluye corrección gramatical asistida por IA ni edición colaborativa simultánea en tiempo real vía WebSockets.

\section{Definiciones}
\begin{itemize}[leftmargin=1.5em, itemsep=2pt, topsep=2pt]
    \item \textbf{TipTap:} Framework moderno de edición enriquecida desacoplado del DOM nativo y estructurado sobre ProseMirror.
    \item \textbf{Debounce:} Técnica de optimización que posterga la ejecución de una rutina asíncrona costosa hasta que transcurre un período de inactividad.

\section{Método, Políticas y Contenidos}
Desarrollo basado en componentes funcionales de React con el cliente Axios institucional con auto-renovación silenciosa de tokens JWT. Se establecen políticas rigurosas:
\begin{enumerate}[leftmargin=1.5em, itemsep=1.5pt]
    \item \textbf{Ventana de Debounce:} La solicitud de persistencia se dispara tras 1500 ms de pausa continua en la digitación.
    \item \textbf{Cancelación Preventiva:} Si el usuario reanuda la escritura mientras existe una petición pendiente, se cancela vía \texttt{AbortController}.
    \item \textbf{Respaldo Local:} En caso de corte prolongado, el texto se preserva en \texttt{localStorage} como contingencia.
\end{enumerate}

\section{Descripción de actividades}

\subsection{Hook de Autoguardado Asíncrono con Debounce}
Se programó el hook \texttt{useAutoSaveSection} que posterga la petición HTTP hasta que transcurran 1500 ms de inactividad:

\begin{lstlisting}[language=Java]
// frontend/src/hooks/useAutoSaveSection.js
import { useState, useEffect, useRef } from 'react';
import api from '../api/client';

export function useAutoSaveSection(docId, claveSeccion, contenido) {
  const [saveStatus, setSaveStatus] = useState('saved');
  const abortRef = useRef(null);

  useEffect(() => {
    if (!docId || !claveSeccion) return;
    setSaveStatus('saving');
    if (abortRef.current) abortRef.current.abort();
    abortRef.current = new AbortController();

    const timer = setTimeout(async () => {
      try {
        await api.put(`/documentos/${docId}/secciones`, {
          claveSeccion,
          contenidoTexto: contenido
        }, { signal: abortRef.current.signal });
        setSaveStatus('saved');
      } catch (err) {
        if (err.name !== 'CanceledError') setSaveStatus('error');
      }
    }, 1500);

    return () => clearTimeout(timer);
  }, [contenido, docId, claveSeccion]);

  return { saveStatus };
}
\end{lstlisting}

\subsection{Extensiones TipTap y Sanitización DOMPurify}
Se configuró el conjunto de extensiones \texttt{StarterKit} para dar soporte a títulos jerárquicos, listas ordenadas y citas. Todo contenido generado pasa por un filtro estricto de sanitización con \texttt{DOMPurify} para neutralizar posibles vectores XSS.

\subsection{Insignias Visuales de Estado}
La interfaz refleja en tiempo real el ciclo de persistencia mediante badges accesibles: \texttt{[Guardando...]} en amarillo ámbar, \texttt{[Guardado en PostgreSQL]} en verde esmeralda institucional y \texttt{[Error de red]} en rojo con reintento asistido.

\subsection{Conclusiones y Recomendaciones Técnicas}
\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
    \item La integración de TipTap con debounce de 1.5s garantiza que el docente nunca pierda su trabajo por descuidos de guardado manual.
    \item El formateo semántico generado es limpio y compatible con los motores de renderizado PDF/Word.
    \item Mantener el almacenamiento de copias locales en \texttt{localStorage} como respaldo de contingencia ante caídas de conexión prolongadas.
\end{itemize}
