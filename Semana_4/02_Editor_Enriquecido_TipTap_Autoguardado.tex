\section{Introducción}
En la elaboración de planes de trabajo e informes de cumplimiento, las secciones descriptivas (Antecedentes, Justificación, Metodología de Cátedra, Conclusiones y Recomendaciones) demandan redacción fluida con soporte para negritas, listas ordenadas, citas y tablas de texto. El uso de campos de texto convencionales degrada la legibilidad y no permite el formateo estructurado requerido por el SGC.

Para subsanar esta limitación, se integró el motor de edición enriquecida **TipTap** (construido sobre *ProseMirror*). Para blindar al docente contra pérdida de datos ante cortes eléctricos o caídas de conexión, se diseñó un mecanismo de **autoguardado asíncrono en segundo plano mediante un hook \texttt{useDebounce} calibrado a 1500 ms**, informando en tiempo real el estado de sincronización con la base de datos PostgreSQL.

\section{Objetivo}

\subsection{Objetivo General}
Implementar el componente de edición enriquecida \texttt{RichTextEditor.tsx} en React 19 basado en TipTap, dotándolo de extensiones tipográficas y sincronización asíncrona automatizada con la WebAPI.

\subsection{Objetivos Específicos}
\begin{itemize}[leftmargin=1.5em, itemsep=1.5pt, topsep=1.5pt]
    \item Configurar TipTap con extensiones de texto: \texttt{StarterKit}, \texttt{Bold}, \texttt{Italic}, \texttt{BulletList}, \texttt{OrderedList}, \texttt{Heading} e \texttt{History}.
    \item Diseñar el hook personalizado \texttt{useDebounce} para emitir solicitudes \texttt{PUT /api/documentos/\{id\}/secciones} tras 1.5s de inactividad.
    \item Mostrar insignias reactivas de estado: \texttt{[Guardando...]}, \texttt{[Guardado]} o \texttt{[Error]}.
\end{itemize}

\section{Alcance}

\subsection{Alcance Incluido}
Componente \texttt{RichTextEditor.tsx} reutilizable para cualquier sección del expediente, sanitización de HTML con DOMPurify y persistencia asíncrona sin bloquear la escritura.

\subsection{Límites y Exclusiones}
El corrector de IA LanguageTool se integra en EDT 3.14.

\section{Definiciones}
\begin{itemize}[leftmargin=1.5em, itemsep=2pt, topsep=2pt]
    \item \textbf{TipTap:} Framework de edición enriquecida moderno desacoplado del DOM nativo.
    \item \textbf{Debounce:} Técnica que retrasa la ejecución de una petición hasta que cesen las modificaciones durante un lapso fijado.
\end{itemize}

\section{Método, Políticas y Contenidos}
Implementación basada en Hooks de React 19 y el ciclo de vida de transacciones de ProseMirror. Se establecen políticas estrictas: las peticiones de autoguardado se ejecutan de manera asíncrona mediante Axios y se cancelan peticiones redundantes mediante \texttt{AbortController} al recibir nuevas entradas antes del timeout.

\section{Descripción de actividades}

\subsection{Algoritmo del Hook de Autoguardado con Debounce}
Se programó el hook \texttt{useAutoSaveSection} que posterga la petición HTTP hasta que transcurran 1500 ms de inactividad:
\begin{verbatim}
export function useAutoSaveSection(docId, claveSeccion, contenido) {
  const [saveStatus, setSaveStatus] = useState('saved');
  useEffect(() => {
    setSaveStatus('saving');
    const timer = setTimeout(async () => {
      try {
        await api.put(`/documentos/${docId}/secciones`, {
          claveSeccion,
          contenidoTexto: contenido
        });
        setSaveStatus('saved');
      } catch (err) {
        setSaveStatus('error');
      }
    }, 1500);
    return () => clearTimeout(timer);
  }, [contenido, docId, claveSeccion]);
  return { saveStatus };
}
\end{verbatim}

\subsection{Extensiones TipTap y Sanitización DOMPurify}
Se configuró el conjunto de extensiones \texttt{StarterKit} para dar soporte a títulos jerárquicos, listas ordenadas y citas. Todo contenido generado pasa por un filtro estricto de sanitización con \texttt{DOMPurify} para neutralizar posibles vectores XSS.

\subsection{Insignias Visuales de Estado}
La interfaz refleja en tiempo real el ciclo de persistencia mediante badges accesibles: \texttt{[Guardando...]} en amarillo ámbar, \texttt{[Guardado]} en verde esmeralda y \texttt{[Error de red]} en rojo con reintento asistido.

\subsection{Conclusiones y Recomendaciones Técnicas}
\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
    \item La integración de TipTap con debounce de 1.5s garantiza que el docente nunca pierda su trabajo por descuidos de guardado manual.
    \item El formateo semántico generado es limpio y compatible con los motores de renderizado PDF/Word.
    \item Mantener el almacenamiento de copias locales en \texttt{localStorage} como respaldo de contingencia ante caídas de conexión prolongadas.
\end{itemize}
